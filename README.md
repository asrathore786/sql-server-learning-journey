# SQL Server Learning Journey

Welcome to my SQL Server Learning Journey repository! 🚀

This repository documents my progress from SQL fundamentals to advanced SQL concepts and Data Engineering. It contains hands-on SQL practice, business-oriented problem-solving exercises, query optimization techniques, and practical examples using Microsoft SQL Server 2022 and SQL Server Management Studio (SSMS).

My goal is to build strong SQL problem-solving skills, understand how to work with complex datasets, and develop the technical foundation required to transition from Business Analysis to Data Engineering.

## What This Repository Covers

- **SQL Fundamentals:** SELECT, WHERE, DISTINCT, TOP, ORDER BY, filtering, and sorting.
- **Joins and Aggregations:** INNER JOIN, LEFT JOIN, FULL OUTER JOIN, GROUP BY, HAVING, and aggregate functions.
- **Subqueries and CTEs:** Nested queries, correlated subqueries, Common Table Expressions, and recursive CTEs.
- **Window Functions:** ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), LEAD(), and analytical calculations.
- **Advanced SQL:** Gaps and Islands, running totals, rolling averages, consecutive activity, trend analysis, and complex business logic.
- **Data Analysis:** Customer behavior, sales trends, monthly performance, customer retention, and reactivation analysis.
- **Data Engineering Concepts:** Payment reconciliation, exception detection, data quality checks, validation, and transformation logic.
- **Query Optimization:** Improving query structure, understanding execution behavior, and developing efficient SQL solutions.

## Hands-On Practice

The repository includes structured SQL exercises, practice datasets, business requirements, and solutions developed as I progress through each topic.

I focus on understanding the logic behind every query rather than simply memorizing syntax. Each exercise helps me improve my ability to translate business requirements into accurate, maintainable SQL.
